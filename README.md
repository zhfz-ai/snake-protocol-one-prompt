SNAKE PROTOCOL: a neon snake game that plays itself when you idle and speeds up every 5 apples, built by an AI agent from one prompt. Open game.html in any browser to play; arrows/WASD take over, idle 4 seconds and the agent drives.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
